Calculations and implementation boundaries

Media duration=frames/24; RTF=E2E/media duration; speedup=baseline median/candidate median. The ordinary offline pipeline uses full history. Recent requires an AR session, uses shared video/text history and incremental_v1 RNG. The API retains 4n+1 frame validation; realtime fixes total frames at start, while typed ticks add turns. Runtime math depends on the pinned reference package.

This integration covers offline generation and normal realtime output. Production service stress, compute-mid-generation cancellation and real blocked TCP sending are outside its acceptance scope. GPU CI and a matched SGLang benchmark have not run.
